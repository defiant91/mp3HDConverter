-----1.1.0-----(1/27/2010)
- Can rename files to Artist - Title
- Minor GUI changes
- Updated toolkit to version 1.5, new features are:
	- Faster En- and Decoding (encode 31% faster, decode 26% faster)
	- Decoding of plain mp3 files
	- Original File Length support for plain mp3 files
	- Some minor bug fixes
	- Encoding of very short input signals
	- Automatic resynchronization to the mp3HD stream on errors
	- Redesign of the mp3HD Winamp quality switch
	- Switched the default mp3HD Encoder ID3 tag version to ID3v2.4 (to overcome Windows 7 issues)
- Checks for administrative rights
